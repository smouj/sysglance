# Commercialization boundary

SysGlance Community remains useful without an account, cloud service, telemetry, ads or AI. The current MIT license is unchanged.

The commercial boundary should be additive and transparent:

```text
Community: real-time metrics, basic layouts, basic shell controls, basic process view
Pro: extended history, advanced alerts, profiles, dashboard customization,
     exports, advanced multi-monitor layouts and diagnostics reports
```

This repository currently contains the community core and the first local history/health/alert domain layer. Licensing, payments, DRM and price checks are not implemented. A plausible future one-time price (€19–29) belongs in product planning, not application code.
